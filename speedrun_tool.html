Understanding the Speedrun Tool Calculation

All credit goes to this tool

This tool calculates the total time from input values representing minutes, seconds, and milliseconds. Below is a breakdown of how the calculation works:

function calculateResult() { total_m = 0; total_s = 0; total_ms = 0; const inputElements = document.querySelectorAll('#input input'); inputElements.forEach(function (element) { const value = parseInt(element.value); if (!isNaN(value)) { switch (element.getAttribute('placeholder')) { case 'Min': total_m += value; break; case 'Sec': total_s += value; break; case 'MS': total_ms += value; break; } } }); total_s += Math.floor(total_ms / 1000); total_ms = total_ms % 1000; total_m += Math.floor(total_s / 60); total_s = total_s % 60; const outputText = `${total_m}m ${String(total_s).padStart(2, '0')}s ${String(total_ms).padStart(3, '0')}ms`; document.querySelector('#output').textContent = outputText; } 

            total_s += Math.floor(total_ms / 1000);
            total_ms = total_ms % 1000;
            total_m += Math.floor(total_s / 60);
            total_s = total_s % 60;
  • Math.floor means adding up integers but not the remainder
  • ms are converted to sec, added to the total sec and remainder is left over
  • seconds are converted to min, added to total mins and remainder is left over
  • % means modulo operator meaning to divide and return the remainder


How Time is Calculated

  1. Input Collection: It collects all input elements from the HTML with the ID input. Each input is expected to have a placeholder indicating whether it represents minutes, seconds, or milliseconds.
  2. Value Parsing: For each input element, the function parses the value as an integer. If the value is a valid number, it adds it to the corresponding total based on the placeholder:
    • If the placeholder is Min, the value is added to total_m.
    • If the placeholder is Sec, the value is added to total_s.
    • If the placeholder is MS, the value is added to total_ms.
  3. Conversion of Milliseconds to Seconds: After collecting all values, the function converts milliseconds to seconds by dividing total_ms by 1000. The integer result is added to total_s, and the remainder (milliseconds that do not convert to a full second) is kept in total_ms.
  4. Conversion of Seconds to Minutes: Next, the function converts seconds to minutes in a similar manner. It divides total_s by 60, adding the integer result to total_m, and keeps the remainder in total_s.
  5. Output Formatting: Finally, the total time is formatted as a string showing minutes, seconds, and milliseconds, ensuring that seconds and milliseconds are displayed with leading zeros if necessary. This formatted string is then displayed in the HTML element with the ID output.
