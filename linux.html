I use Fedora, by the way.

This image was taken from the terminal using the fastfetch program. Some interesting things to point out include the window manager which is Sway, and the terminal I'm using, which is ghostty.

My system is very minimal compared to what you may be used to if you use Windows a lot. In this page I'll describe my system in more detail and show you what makes it really great to me.

You can also see my setup uses two monitors. You definitely don't need multiple monitors to get ahead but for me it is wonderful (most of the time) and it will be relevant in things like setting sway workspaces and setting the sizes of floating windows and such.

The next thing to point out is the bottom where the cursor is. Mine looks this way because of Oh-My-Posh, a beautiful terminal prompt theme engine. You can choose from many themes and display all kinds of helpful information. Check it out here.

The last thing to mention on this image is the Terminal Font, which is a Nerd Font. Nerd fonts are fantastic advanced fonts which include several icons that show up in terminal programs such as Oh-My-Posh, Yazi file manager, Neovim, and others.
